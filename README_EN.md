# Legend of the Starlight Sword - Project Overview

[Chinese](https://github.com/RUIYUN-ML/SafeLLMPlayground/blob/main/README.md) | English

![Starlight Sword - Prologue title screen](/assets/images/%E5%BA%8F%E7%AB%A0%E9%A6%96%E5%B1%8F.png)

An educational mini-game about **LLM prompt safety**. You play as a hero and talk to a speaking Starlight Sword, learning concepts such as **prompt injection, jailbreak attacks, and defenses** through story-driven play. 

**Live demo**: [Click Here](http://124.223.115.66:8001/Front-end%20development/%E4%B8%BB%E9%A1%B5/login.html)

## Contents

- Chapter 2: Defense levels
